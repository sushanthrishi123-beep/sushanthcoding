# Sushanth Coding website

A responsive beginner-friendly coding learning website built with plain HTML, CSS and JavaScript.

## Preview on your computer
1. Download and unzip `sushanthcoding-website.zip`.
2. Open the `sushanthcoding-website` folder.
3. Double-click `index.html` to open the website in your browser.
4. Edit the files with Notepad++ if you want to customize the content.

## Publish free with GitHub Pages
You need a free GitHub account.

1. Sign in at https://github.com.
2. Create a new public repository named `sushanthcoding-website`.
3. Upload `index.html`, `styles.css`, and `script.js` from this folder to the repository's main branch (root).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. GitHub will show your public website address in the Pages section.

## About sushanthcoding.com
The website files are ready, but a custom `.com` domain must be registered separately (it is not included for free with GitHub Pages).

After you purchase/register `sushanthcoding.com` through a domain registrar:
1. In your GitHub repository, go to **Settings → Pages → Custom domain** and enter `sushanthcoding.com`.
2. Follow GitHub's current DNS instructions for the domain. At the registrar, add the DNS records GitHub specifies (typically A records for the apex domain and a `www` CNAME).
3. Wait for DNS to update, then enable **Enforce HTTPS** in GitHub Pages when it becomes available.

Do not share your GitHub password with anyone. You can send a screenshot of the GitHub Pages settings if you want step-by-step help.
